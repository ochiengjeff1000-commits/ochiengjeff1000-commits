## 🚀 Featured Projects

### 🏫 [EduSkul](https://eduskul.techsquarehub.co.ke): CBC School Management SaaS
**Founder & Sole Developer · Live in production**

A multi-tenant platform for Kenyan CBC schools, owned end-to-end from schema to UI to server deployment.

- Academic engine: three-sitting exam scoring, KNEC 8-band grading, dynamic marklists, auto-generated report comments and year-end learner promotion
- Role-based access (Head Admin, Deputy Admin, Clerk, Teacher) with per-account permission gating for finance and staff management
- M-Pesa billing, per-school SMS and PDF report/receipt generation
- Fixed recurring Prisma engine crashes caused by CloudLinux process-thread limits by re-engineering the deploy pipeline around raw SQL migrations and pre-compiled binaries

`Node.js` `Express` `Prisma` `MySQL` `React` `Vite` `Tailwind`

### ✅ [CBA Score Validator](https://techsquarehub.co.ke/cba-score-validator): Chrome Extension & Licensing System

Turns a school's Excel or PDF marksheet into a clean dataset, then auto-fills every score on the live KNEC CBA portal in one click.

- Privacy-first: the dataset builder and extension run entirely client-side, so no learner score data touches a server
- Custom PHP/MySQL licensing backend with school registration, M-Pesa license purchase, server-side verification and device fingerprinting

`JavaScript` `Manifest V3` `PHP` `MySQL`

### 📋 Exam Invigilation & Supervision Allocator

A tool that automates the allocation of teachers as invigilators and supervisors for **KPSEA, KJSEA and KCSE** across hundreds of schools. It replaces a slow, error-prone manual process.

- Rule-based allocation with configurable candidate-to-staff ratios and a rules tab to override the defaults
- Honors teachers' preferred schools, then tops up under-staffed schools so no centre is left short
- Spreads supervisors fairly across public schools, with separate KPSEA/KJSEA and KCSE rules
- Manual controls to move, replace or remove teachers, add schools, and shuffle allocations
- Flags teachers who missed automatic placement and schools with shortfalls, so they're easy to fix
- Exports printable allocation sheets for schools and for the exam centres

`JavaScript` `HTML` `Python`
